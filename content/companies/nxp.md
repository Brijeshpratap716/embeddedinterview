## How the process usually runs

Campus candidates in India describe an online assessment, often around an hour of MCQs on C and OS with a strong focus on pointer arithmetic (one report: 35 questions, with negative marking), sometimes plus coding questions. Shortlisted candidates then have an hour-long technical interview on C, the resume and core subjects, and occasionally a second round or HR call. In Europe (Bucharest, Brno), candidates describe C/C++, memory management, algorithms, bitwise operators, preprocessor directives and optimisation questions.

## Topics that come up most

- **C and pointers:** output-based questions, pointer arithmetic → [C Programming](../../topics/c-programming/), [Pointers & Memory](../../topics/pointers-memory/)
- **Memory layout and compilation:** where variables are stored, compilation steps, why `main` is the entry point → [Pointers & Memory](../../topics/pointers-memory/)
- **Bitwise operators and the preprocessor** → [Bit Manipulation](../../topics/bit-manipulation/)
- **OS and microcontrollers** → [Operating System Concepts](../../topics/operating-systems/), [Microcontrollers & ARM](../../topics/microcontrollers-arm/)
- **Data structures:** linked lists, arrays, BST vs B-tree → [Data Structures](../../topics/data-structures/)

## Questions candidates reported (paraphrased)

- Where in memory is each variable in this program stored?
- What are the stages of compiling a C program?
- Why is `main` the entry point?
- Pointer-arithmetic output questions.
- Linked-list and array coding problems.
- How would you program this microcontroller? (project-based)

## How to prepare

1. Practise C output questions until you can trace pointer arithmetic and integer promotion reliably.
2. Know the memory layout of a C program and the compilation pipeline thoroughly; see the article [Memory Layout of a C Program on a Microcontroller](../../articles/memory-layout-mcu/).
3. For automotive teams, revise CAN and safety basics; for security teams, crypto and secure boot basics.
